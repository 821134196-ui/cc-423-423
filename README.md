# 🐾 暖爪 · 宠物美容预约与护理记录系统

管理宠物档案、服务项目、美容师、预约时段、皮肤毛发备注、用品消耗、照片与取宠确认。

- **零第三方依赖**：仅 Python 3.9+ 标准库（`sqlite3` / `http.server` / `threading`），前端原生 HTML/CSS/JS。
- **存储**：SQLite 保存预约与护理记录（`data/grooming.db`），本地目录保存照片（`data/photos/`）。
- **提醒**：进程内后台线程扫描超时未取并重试失败通知（指数退避）。

## 单条本地启动命令

```bash
python3 run.py
```

首次启动自动建库、写入宠物与联系人演示数据，并预置：

| 样例 | 内容 |
| --- | --- |
| 奶茶（当前时段） | 护理中，1/2 项目完成；皮肤异常 + 宠物抗拒事件及异常照片；已登记用品消耗 |
| 豆豆（当前时段） | 已预约待接待（与奶茶同时段，演示工位容量可并行） |
| 布丁（上一时段） | 全部项目完成并结单、待取宠；含剪伤事件与异常照片 |
| 拿铁（昨天） | 已结单超时未取：超时事件 + 取宠提醒，其中一条通知模拟网关失败持续重试 |
| 未来时段 | 奶茶复洗预约 |

时段相对当前整点锚定，任何时刻启动样例状态都合理。

常用参数：`--reset`（删库重建样例）、`--port 8000`、`--no-browser`、`--no-scheduler`。

## 六个界面

1. **📅 预约日历**：按时段分组；新建预约保存品种/体型/禁忌快照、服务组合与预计时长；接待确认、临时改项、取消、登记事件入口。
2. **🐶 宠物档案**：照片 + 标签卡片；点开查看皮肤毛发备注、禁忌、联系人与近期异常。
3. **🏗️ 工位排程**：按时间轴展开每位美容师，标注容量/已锁定数，满员时段橙色斜纹。
4. **✂️ 护理录入**：大号状态按钮，完成一项点一项（可撤销）；未完成不能结单；用品消耗（可勾选用品过敏）；事件图标 + 文字 + 照片缩略图。
5. **⚠️ 异常照片**：六类事件（宠物抗拒/皮肤异常/剪伤/主人临时改项/超时未取/用品过敏）筛选；未授权显示 🔒。
6. **🏷️ 取宠核验**：结单生成 6 位取宠码，凭取宠码或预留手机号核验，重复核验被拒；底部展示通知发送与重试状态。

主题色：柔和绿 `#8fbf9f`、海军蓝 `#2b3a55`、桃色 `#f6c6a8`。

## 业务规则

- 预约创建在 `BEGIN IMMEDIATE` 事务内做三重校验：**同一宠物同一时段唯一**（DB 部分唯一索引兜底）、美容师同时段只能一单、**工位容量锁定**。
- 接待确认后生成护理单与逐条护理项目；**服务项目完成一项记录一项**。
- 存在未完成项目 → 拒绝结单（409）；结单（护理记录确认）后**不能删除、不能重复结单、不能改项目**。
- 主人临时改项：接待前改预约明细并重算时长；接待后同步护理条目，已完成条目不可移除；每次改项生成事件。
- 异常照片 `sensitivity=restricted`：内容接口对未授权用户返回 403，元数据可见但前端只显示锁定占位。
- 超时未取（默认结束后 180 分钟）扫描幂等，只生成一次事件并入队提醒。
- 通知失败按 5s/10s/20s/40s 指数退避重试，最多 5 次后置 `failed`。

## 测试

```bash
python3 -m unittest tests.test_system -v
```

18 个用例覆盖：

- **时段竞争**：容量 2 时段 3 线程并发抢锁（恰 2 单成功）、同宠同时段并发唯一、美容师冲突、快照与时长；
- **服务变更**：接待前改项重算时长、接待后已完成项目不可删除/新增项同步、结单后不可改；
- **照片权限**：真实 HTTP 链路下未登录 401 / 美容师 403 / 店长 200，越权上传 403；
- **重复结单**：未完成拒结、结单后重复结单 409、确认后删除 403、取宠错误码 403 与重复核验 409；
- **通知重试**：指数退避节奏、达上限 failed、首试成功 sent、后台调度线程真实投递、超时扫描幂等。

## 目录结构

```
run.py                 # 启动入口（建库/预置/起服务/起提醒线程）
app/
  config.py            # 路径、容量、退避、主题色
  db.py                # SQLite 连接与 schema（含同宠同时段唯一索引）
  auth.py              # 演示账号与会话
  photos.py            # 本地照片存取（防路径穿越、data URL 解码）
  operations.py        # 全部业务规则与状态机
  notifier.py          # 进程内通知重试 + 超时扫描线程
  seed.py              # 演示数据与样例（纯色 PNG 现场生成）
  server.py            # HTTP 路由 + JSON API
  static/              # index.html / styles.css / app.js
tests/test_system.py
```
